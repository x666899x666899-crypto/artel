# 99_Архив

Сюда переносят всё, что «не нужно» в рабочих папках. **Ничего не удаляем** — место на диске дешевле потерянных данных.

## Как класть

- Подпапка по дате: `YYYY-MM-DD_краткое-описание/`
- Или один файл: `YYYY-MM-DD_имя-файла.ext`

## Примеры

- `2026-08-10_старые_прайсы/`
- `2026-08-10_дубликат_сметы.xlsx`

## Правило для ИИ

Удаление запрещено. Любая «уборка», «ротация», «очистка» = только **перенос сюда**.
