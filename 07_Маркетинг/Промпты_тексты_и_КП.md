## Коммерческие предложения

### `/кп` — базовое КП

```
Напиши коммерческое предложение АРТЕЛЬ.

Клиент: [имя, компания]
Задача: [что хочет решить]
Предложение: [вывеска / полиграфия / оформление…]
Цена: [только из нашего расчёта / прайса — не выдумывать]
Срок: [изготовление + монтаж]
Преимущества: собственное производство, полный цикл, Улан-Удэ, [ещё 1–2 пункта]

Структура:
1. Заголовок — боль клиента или результат
2. Понимаем задачу (2–3 предложения)
3. Наше решение (что и как делаем)
4. Почему АРТЕЛЬ (3 аргумента)
5. Состав работ, стоимость, сроки (таблица — см. _Шаблон_КП.md)
6. Следующий шаг для клиента

Стиль: деловой, живой, без канцелярита. Одна страница.
Монтаж и доставка — отдельными строками. Без себестоимости.
```

Готовое КП → `03_КП_и_сметы/Архив_КП/YYYY-MM-DD_клиент_объект.md`

### `/кп-холод` — холодный клиент

```
Короткое КП АРТЕЛЬ для холодного клиента — нас не знает.

Кто: [отрасль, размер, боль]
Что предлагаем: [продукт/услуга]
Главная выгода: [конкретный результат]

Цель: заинтересовать, получить ответ — не продать с первого касания.
5–7 предложений. Закончи вопросом или следующим шагом.
Tone of voice: 07_Маркетинг/Tone_of_voice.md
```

### `/апсейл` — допродажа

```
Клиент АРТЕЛЬ уже покупает: [что сейчас]
Предлагаем дополнительно: [продукт/услуга]
Логика: [связь с текущим заказом]

Короткое сообщение Telegram/WhatsApp — как совет, не продажа.
Естественно, без давления.
```

## Авито и маркетплейсы

### `/авито`

```
Объявление АРТЕЛЬ на Авито.

Продукт: [вывеска / баннер / табличка…]
Аудитория: [кто ищет]
Характеристики: [размеры, материал, срок]
Цена: [из прайса]
Плюсы: собственное производство, монтаж, гарантия

Структура:
- Заголовок до 50 символов, ключевое слово первым
- Первые 2 предложения — боль или выгода
- Описание
- Почему мы / гарантии
- Призыв к действию

Тон: дружелюбный, уверенный, без «кричащих» слов.
Контакты: zavodartel.ru, +7 (3012) 37-82-21
```

### `/заголовки`

```
10 заголовков для Авито — АРТЕЛЬ.

Продукт: [что продаём]
Ключевые слова: [по которым ищут]
Главная выгода: [для покупателя]

Разные подходы: выгода, вопрос, цифра, гарантия, срок, «под ключ».
До 50 символов каждый.
```

## Посты и контент

### `/пост`

```
Пост АРТЕЛЬ для [VK / Telegram].

Тема: [тема]
Аудитория: [бизнес Улан-Удэ / B2B / федеральные сети]
Цель: [информировать / продать / вовлечь / экспертиза]

Структура:
- Первая строка — цепляет (вопрос, цифра, факт)
- Проблема или контекст
- Суть / решение / кейс
- Вывод или призыв

До 800 символов. Tone_of_voice.md. Без воды.
```

### `/контент`

```
Контент-план АРТЕЛЬ на 7 постов [VK / Telegram].

Тематика: завод рекламы, вывески, полиграфия, кейсы, производство
Аудитория: [кто]
Цель: [узнаваемость / продажи / доверие]

На каждый пост:
- Тема
- Цель
- Первая строка (крючок)

Чередуй: польза, история, кейс, мнение, продающий.
```

## Переписка с клиентами

### `/жалоба`

```
Клиент написал жалобу: [текст]

Ответ от АРТЕЛЬ:
- Признай проблему без оправданий
- Что делаем для решения
- Конкретный следующий шаг

5–7 предложений. Спокойно, по-человечески, не шаблонно.
```

### `/оплата`

```
Клиент не оплатил счёт. Просрочка: [N] дней.

Мягкое напоминание в мессенджер от АРТЕЛЬ.
3–4 предложения, без давления.
Закончи вопросом или предложением помочь, если что-то не так.
```

### `/после-встречи`

```
Встреча с клиентом АРТЕЛЬ.

Договорились: [список]
Наш следующий шаг: [что делаем]
Шаг клиента: [что от него]

Короткое письмо/сообщение: зафиксировать договорённости + next step.
Деловой и дружелюбный. Без лишнего.
```

*Для разбора расшифровки встречи на задачи — `/разбор`.*
