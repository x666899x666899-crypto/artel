# Бланки производства

Печатные формы в фирстиле АРТЕЛЬ (гайдбук 2026).

| Файл | Назначение |
|---|---|
| `АРТЕЛЬ_заказ_наряд_чек_лист.html` | Двухсторонний заказ-наряд + чек-лист бригадира (A4) |
| `_assets/` | Логотипы PNG (с сервера, rgb) |

## Как получить PDF

1. Открыть HTML в браузере.
2. Ctrl+P → принтер «Сохранить как PDF» → поля: минимум полей, фон включён.
3. Готовый PDF при необходимости положить рядом или на сервер в `Брендбук Артель\2026\` (только по команде Сергея).

Исходник старого бланка: `\\serverartel\Обменник 3.0\Брендбук Артель\2026\заказ наряд + чек лист  (4).pdf` (+ `.cdr`).
