## Листы

### По месяцам (основное движение)

Имя листа = **`MM.YYYY`** (пример: `07.2026`, `08.2026`, `09.2026`).  
Есть с `07.2024` по `12.2026` (часть будущих месяцев — заготовки).

Для сводки брать **лист текущего месяца** или период, который назвал Сергей.

## Структура месячного листа

### Блок 1 — шапка «Движение средств на текущий момент»

По каждому счёту: **Приход**, **Расход**, **Остаток** за месяц + **остаток на начало месяца**.

Основные счета (операционный контур):

- Наличка  
- Карта СБЕР серая Шенхоров / СБЕР зеленая / ВТБ / ВТБ бизнес / Альфа ФЛ  
- Счет ВТБ Шенхоров  
- Счет Альфа Шенхоров  
- Счет Альфа Артель  

Отдельно: Взаимозачет; налоговые и амортизационные счета (Артель / ИП Шенхоров).

Строка **«Итого остатки»** — суммарно по основным счетам.

Справа в шапке встречаются метки прихода: Расход / Дивиденды / СН / ВБ — служебные ярлыки, не путать с оборотом.

### Блок 2 — журнал операций (с строки «Дата транзакции»)

| Колонка | Что значит | Как использует финансист |
|---|---|---|
| **Дата транзакции** | дата операции | фильтр периода |
| **Счет** | с какого счёта / карты | остатки, разрезы |
| **Приход/Расход** | направление | знак суммы |
| **Категория** | статья ДДС | топ расходов / структура |
| **Сумма** | сумма в руб. | агрегаты |
| **Контрагент** | кто / кому | дебиторка, поставщики |
| **Менеджер** | чей приход (часто с %) | продажи, % менеджеров |
| **% оплаты** | % менеджера со сделки | только внутренние отчёты |
| **Примечание** | номер счёта, комментарий | разбор строки |

## Категории (факт июля 2026)

Частые: **Перемещение между счетами**, **Без категории** (часто оплаты клиентов), **Закуп материалов**, **ФОТ**, **Постоянные расходы**, **Банковские/комиссии**, **Командировочные/ вечеровки**, **Подрядчики**, **Транспортные услуги**, **ГСМ**, **Налоги**, **Дивиденды**, **Амортизация**, **Капитальные вложения**, **Спецтехника**, **Возврат/откат**, **Инвестиции**, **Представительские расходы**.

**Важно:** «Перемещение между счетами» — не расход бизнеса. В чистом ДДС (операционный результат) **исключать** или показывать отдельно.

### ФОТ — календарь выплат (не путать с «зарплатой месяца»)

Подробно: `агенты/ФИНАНСИСТ/_КОНТЕКСТ/фот_календарь.md`.

- **Аванс** текущего месяца M → ~**20-е** месяца M (в том же листе).
- **Зарплата** за месяц M → **после 5-го следующего** месяца (M+1). Пример: зарплата за июль → после 5 августа.
- В ФОТ листа: зарплата **прошлого** месяца + аванс **текущего**. Сравнивать месяцы по ФОТ только с этой оговоркой.

## Правила для агента

1. Сводка за месяц → лист `MM.YYYY`. Нет листа — сказать.  
2. Операционный приход/расход: без строк «Перемещение между счетами», если Сергей не просил «все обороты».  
3. «Без категории» на приходе — обычно оплаты клиентов; не переименовывать без команды.  
4. **% оплаты**, **ФОТ**, **Дивиденды** — только Сергею, не в клиентские тексты.  
5. Таблицу не менять без явного «запиши».  
6. Цифры только из выгрузки/таблицы. Нет доступа — сказать прямо.

## Связанные системы

- **1С** — бухгалтерия, выписки (не подменять ДДС).  
- **Битрикс** — сделки; сверка «счёт ↔ приход» по примечанию (`сч. …`).
