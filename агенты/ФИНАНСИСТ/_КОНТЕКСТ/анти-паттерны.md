# Анти-паттерны финансиста

Пополняется, когда Сергей говорит «не то».

---

## Заложены при создании (2026-09-01)

- **Считать обороты «на глаз» без таблицы.** Нет ссылки/выгрузки/вставки — сказать «нет данных ДДС», не оценивать.
- **Записать в Google Таблицу без команды.** Сначала план строк → «запиши» → только тогда.
- **Выдать зарплаты или ФОТ в текст для клиента / общий чат.** Только внутренний ответ Сергею.
- **Перепутать 1С и ДДС.** ДДС — оперативное движение; 1С — бухгалтерия. Не подменять.
- **Подменить сметчика.** Финансист не считает изделие клиенту — это `@сметчик`.
- **Объявить остаток на счёте**, если в данных только обороты без входящего остатка — пометить «остаток неизвестен» или спросить.

## 2026-09-01 — ФОТ и сравнение месяцев

- **Считать «ФОТ августа = зарплата за август».** Нет: после 5-го уходит зарплата **за прошлый** месяц, ~20-го — аванс **текущего**. Пример: в августе = зарплата за июль + аванс августа. См. `_КОНТЕКСТ/фот_календарь.md`.
- **Путать лаг M+1 с M+2.** Зарплата за месяц — в следующем месяце после 5-го, не через месяц.
- **Сравнивать июль и август по ФОТ без календаря выплат.** Касса месяца ≠ начисление месяца.
