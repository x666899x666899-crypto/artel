# Агент «Финансист»

Деньги и учёт АРТЕЛЬ. Опора — Google Таблица **«НОВОЕ ДВИЖЕНИЕ СРЕДСТВ»**.

## Как вызвать

```
@финансист сводка за неделю
```

```
@финансист сводка за август 2026
```

```
@финансист разбери эти строки выписки / фото
```

```
@финансист где кассовый разрыв в этом месяце?
```

## Откуда цифры

1. **Основное:** [НОВОЕ ДВИЖЕНИЕ СРЕДСТВ](https://docs.google.com/spreadsheets/d/1qeWN0sCkaWOSjoYKln1uD1eSvuyjDppPtf9LybmeJts/edit) — карточка: `_КОНТЕКСТ/источник_ДДС.md`
2. Лист месяца: `MM.YYYY`
3. Выгрузка Excel/CSV в `10_Финансы_и_аналитика/ДДС/`
4. То, что вы вставили в чат

Нет доступа к таблице и нет выгрузки — скажет прямо, не будет фантазировать.

## Что получите

1. **Суть** — приход / расход / сальдо за период  
2. **Детали** — по статьям, крупные платежи  
3. **Для Telegram** — короткий блок на телефон  
4. **Что сделать** — внести, уточнить у кассира, решить

## Правила

- Не правит Google Таблицу без вашего «запиши».
- Не заходит в банк и не проводит оплаты.
- Зарплаты и ФОТ — только вам, не клиентам.
- Удаление файлов запрещено.

## Папки

| Папка | Зачем |
|---|---|
| `_КОНТЕКСТ/источник_ДДС.md` | ссылка, листы, колонки таблицы |
| `_КОНТЕКСТ/примеры/` | удачные сводки |
| `_КОНТЕКСТ/анти-паттерны.md` | ошибки |
| `_ЛОГИ/` | дневник сводок |
