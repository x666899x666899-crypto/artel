# Агент «Кладовщик»

Материалы, цены, еженедельная сверка с поставщиками, потребность под заказ, разбор прихода.

## Как вызвать

```
@кладовщик сверка цен
```

```
@кладовщик какая у нас цена на акрил молочный 3 мм? Колонка Стоимость.
```

```
@кладовщик вот раскладка сметы — что закупить, чего нет в справочнике
```

```
@кладовщик вот фото УПД — разнеси в таблицу прихода
```

```
@кладовщик да, обнови позиции из блока «критично»
```

## Что делает

| Задача | Результат |
|---|---|
| Сверка цен | отчёт в `_КОНТЕКСТ/сверки/` + короткий блок для Telegram; файлы сам не меняет |
| Цена материала | наша из Форы/Excel → иначе ориентир с сайта с пометкой |
| Потребность | список к закупке/проверке по смете сметчика |
| Приход | таблица из УПД/накладной |

## Откуда цены

1. `03_КП_и_сметы/Расчёты/Фора_шаблоны/Материалы.xlsx` (Стоимость / ОПТ / РПК)  
2. `Номенклатура_материалов.md`, прайсы в `10_Финансы_и_аналитика/Прайсы/`  
3. Сайт поставщика — только как **ориентир**, пока не сказали «да, обнови»

Остатки на складе — Google Таблица «Склад Артель» (`_КОНТЕКСТ/остатки_склад.md`) или выгрузка/ваша цифра.

## Связка со сметчиком

- `@сметчик` — считает изделие клиенту  
- `@кладовщик` — откуда цена, актуальна ли, что докупить, разбор прихода
