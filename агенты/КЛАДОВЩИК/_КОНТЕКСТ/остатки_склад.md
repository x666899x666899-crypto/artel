## Типовые колонки (на примере листа 10)

- №, Код материала, Наименование, Ед. изм.
- Остаток на начало месяца → Приход → Расход → Остаток на конец месяца  
  (формула: начало + приход − расход)

## Правила для агента

1. Остатки брать **только** из этой таблицы (или свежей выгрузки CSV/Excel в базу).
2. Указывать лист, код/наименование, дату остатка (какая колонка: начало/конец месяца).
3. Отрицательный остаток — флаг «проверить у склада», не «исправлять» сам.
4. Цены — по-прежнему из себестоимости / мониторинга, не из этой таблицы (если в ней нет цен).
5. Файл в базе: при выгрузке класть в `агенты/КЛАДОВЩИК/_КОНТЕКСТ/остатки/YYYY-MM-DD_склад.csv` (или xlsx).
