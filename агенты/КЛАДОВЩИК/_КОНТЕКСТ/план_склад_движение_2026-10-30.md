# План: удобное движение склада (Склад Артель)

Дата: 2026-10-30. Таблица: [Склад Артель](https://docs.google.com/spreadsheets/d/1FkmTr21AwVoU8U08msIxce8stk2e36I96vqGLjWk68w).  
Пока только план — правки в таблице после «ок, делай».

## Что уже есть (анализ)

1. **Журналы по месяцам** (`09.2026`, `10.2026`, …): строки «Дата | Приход/Расход | Склад | Наименование | Код | Ед. | Объём».
2. **Категорийные листы** (`1. Расх_мат` … `11. Сувенирка`): остатки считаются формулами `SUMIFS` с месячных листов + цепочка «начало + приход − расход».
3. **База_материалы** (~1960 строк): код, название, ед.изм. — справочник для выпадающих списков.
4. **База**: список складов/категорий, ед.изм., менеджеры.
5. **Цен в таблице нет** — ни на движении, ни на остатках.
6. Минусы сейчас: каждый месяц новый лист; надо лазить по вкладкам; нет цены и суммы на складе; для новичка сложно.

## Целевая картина «для склада»

Три рабочих экрана (остальное — архив/справочник):

### 1) Лист `ДВИЖЕНИЕ` (первый, закреплённый)

Одна строка = один приход или расход. Человек **не ходит** по категорийным листам.

| Поле | Как |
|---|---|
| Дата | дата |
| Тип | Приход / Расход (список) |
| Категория (склад) | список из `База` |
| Наименование | список из `База_материалы` (фильтр по категории — этап 2) |
| Код | подтягивается сам |
| Ед.изм. | подтягивается сама |
| Количество | ввод |
| Цена за ед. | ввод **обязателен на Приходе**; на Расходе — подсказка средней/последней |
| Сумма | = кол-во × цена |
| Поставщик / документ / комментарий | текст |
| Кто внёс | имя |

Цвет: приход — зелёный, расход — красный. Фильтр сверху: «сегодня / этот месяц / всё».

### 2) Лист `ОСТАТКИ` (второй)

Сводка «что есть сейчас» + деньги:

- Категория | Код | Наименование | Ед. | Кол-во | Цена учётная | Сумма на складе  
- Кол-во = сумма приходов − сумма расходов из `ДВИЖЕНИЕ` (+ стартовый остаток после инвентаризации)  
- Цена учётная = средняя взвешенная по приходам (или последняя цена прихода — выбрать)  
- Итого ₽ внизу / по категориям  
- Красным — отрицательные / нулевые критичные позиции  

Поиск по названию — обычный Ctrl+F / фильтр.

### 3) Категорийные листы 1–11

Оставить как **детальный просмотр по типу материала** (привычка Бориса/склада), но:

- приход/расход **не вбивать вручную** в широкие колонки месяцев;  
- они либо зеркалят `ОСТАТКИ` / `ДВИЖЕНИЕ`, либо упрощаются до: код, название, ед., **текущий остаток**, **цена**, **сумма**.  

Старые помесячные колонки (с 2024) → в архив / скрыть после перехода.

### 4) Месячные листы `MM.YYYY`

После перехода: не создавать каждый месяц. История живёт в `ДВИЖЕНИЕ`. Старые месяцы — только архив (не трогаем).

## Цены — правило

- На **каждом приходе** обязательна цена за единицу (шт / м² / пог.м / кг…).  
- На складе видно: количество × учётная цена = сумма по позиции.  
- Расход списывает количество; сумма склада пересчитывается.  
- Старт после инвентаризации: можно занести «вводной остаток» строками Приход с пометкой «Инвентаризация YYYY-MM-DD» и ценой.

## Что не трогаем без отдельной команды

- `Инвентарь` (инструмент по бригадам) — другая учётка.  
- `Заявки` — можно позже связать с расходом.  
- Исторические месячные листы 2024–2025 — только архив.

## Риски

- Широкие старые листы тяжёлые (~1000 строк × десятки месяцев) — после перехода лучше упростить.  
- Обрезки (`3. Обрезки_лист`) — другая логика (размер Ш×В), отдельный мини-режим.  
- Без цены на стартовых остатках «деньги на складе» будут неполными — закладываем в этап 4.
