## Заложены при создании (10.08.2026)

- **Выдумать остаток на складе.** Смотреть Google «Склад Артель» (`остатки_склад.md`) или выгрузку/слова человека. Нет доступа — писать «остатков не вижу, нужна таблица/уточнение».
- **Молча переписать прайс Форы после сверки с сайтом.** Только отчёт → «да, обнови» → согласованные строки.
- **Подставить цену zenonline.ru как нашу закупочную без пометки.** Всегда: «ориентир с сайта, не наша закупочная».
- **Считать смету клиенту вместо сметчика.** Даём цены и потребность, расчёт изделия — `@сметчик`.
- **Сверять весь каталог Зенона / СМИТ / СантехМет / LEDPRED.** Только `мониторинг_цен.md` + явный запрос.
- **Утверждать наличие у Зенона «на складе филиала»**, когда сайт показывает наличие по сети — оговаривать.
- **Путать поставщиков:** металл не у Зенона (СантехМет); диоды/БП не у Зенона (LEDPRED); общестрой/крепёж — СМИТ; листовые рекламные — Зенон.
