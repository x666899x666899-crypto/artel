# Расписание кладовщика

## Еженедельная сверка цен

| | |
|---|---|
| Когда | **каждый понедельник** (утро, Улан-Удэ) |
| Команда | `@кладовщик сверка цен` |
| Список | `_КОНТЕКСТ/мониторинг_цен.md` |
| Отчёт | `_КОНТЕКСТ/сверки/YYYY-MM-DD_сверка.md` + блок Telegram |
| Файлы цен | **не менять**, пока Сергей/Василий не скажет «да, обнови» |
| Если с прошлой сверки &lt; 5 дней | напомнить дату и спросить «заново?» |

Cursor Automation (если включена): то же самое по расписанию, без ручного запуска.

## После «да, обнови»

1. Править только согласованные строки в `Себестоимость_материалов.md` и клиентские в `Номенклатура_материалов.md` (обычно ×1.1).
2. Записать в отчёт сверки: старая → новая, кто подтвердил.
3. Сообщить: справочник обновлён — учитывать `@сметчик`.
