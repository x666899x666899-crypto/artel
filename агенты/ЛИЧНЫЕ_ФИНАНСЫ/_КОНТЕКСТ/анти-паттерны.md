# Анти-паттерны «Личные финансы»

Пополняется, когда Сергей говорит «не то».

---

## Заложены при создании (2026-09-01)

- **Считать личное по ДДС АРТЕЛЬ.** Завод — `@финансист`. Сюда — только журнал / чат / личная таблица.
- **Выдумать остаток на карте**, если в `счета.md` пусто и Сергей не назвал сумму.
- **Записать в журнал без «запиши».** Сначала список строк → подтверждение → запись.
- **Показать личные суммы в КП, посте, чате с клиентом или командой.** Только Сергею.
- **Считать перевод между своими картами расходом.** Пополнение кредитки — тоже не расход.
- **Не заводить статью**, если трата явно системная (аптека, ЖКХ). Справочник живой.
- **Подтянуть «Альфа ФЛ» из ДДС завода как личный счёт** без слов Сергея.
- **Смешать дивиденды Василия и Сергея.** Неизвестно чей вывод — спросить.
