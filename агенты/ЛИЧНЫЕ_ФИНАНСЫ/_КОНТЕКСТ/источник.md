1. Сводка → лист **Журнал** (статус `ок`; черновики помечать).

3. **Входящее** пишет бот сам. **Журнал** — агент после разбора (черновик) или по «запиши».
4. Цифры только из таблицы / чата. Нет доступа — сказать прямо.
5. Таблицу не открывать «всем по ссылке» — личные деньги.
