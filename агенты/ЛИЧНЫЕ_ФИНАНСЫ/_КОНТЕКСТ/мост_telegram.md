## Спросить у бота

|---|---|
| `остатки` | все счета, живые ₽ без кредитки |
| `сводка` | расход/приход за месяц + остатки |
| `сколько продукты` | сумма по статье за месяц |

| `бюджет` | план vs факт |

| `сколько на альфе` | один счёт |

## Что сделать Сергею (5 минут)

**Телефон — создать бота**

1. Telegram → **@BotFather** → `/newbot`
2. Имя: `Личные финансы` (как угодно)
3. Username: например `artel_lichnoe_bot` (должен заканчиваться на `bot`)
4. BotFather пришлёт **токен** (длинная строка). Пришли его **в этот чат Cursor** — дальше доделаю я. Никому больше не пересылай.

**Компьютер — если делаешь сам**

1. В Cursor открой `агенты/ЛИЧНЫЕ_ФИНАНСЫ/_КОНТЕКСТ/Apps_Script_телеграм.js` → Ctrl+A → Ctrl+C
2. Вкладка Apps Script (уже открыта) → в коде Ctrl+A → Ctrl+V → сохранить (диск)
3. Слева «Настройки проекта» (шестерёнка) → Свойства скрипта → `TELEGRAM_TOKEN` = токен
4. Развернуть → Новое развёртывание → тип **Веб-приложение** → выполнять от себя → доступ **все, у кого есть ссылка** (это для Telegram, не для людей) → Развернуть → разрешить доступ Google
5. Сверху выбрать функцию `registerWebhook` → Выполнить
6. В Telegram написать боту `/start`, потом «тест 350»

Токен и URL веб-приложения — только в `99_Конфиденциально/Личные_финансы/_секреты.md`, не в чаты и не в КП.

## Что делает агент

Команда: `@личныефинансы разбери входящее`

1. Читает строки со статусом `новое`.
2. Достаёт сумму и статью (с фото/чека/SMS/расшифровки голоса).
3. Пишет черновик в **Журнал**, во входящем — `разобрано` или `вопрос`.
4. Неясное — список вопросов, не выдумывает.

Голос: если нет подписи текстом — сначала расшифровка, потом сумма. Подпись к фото («кофе 350») ускоряет разбор.

1. Cursor: файл `агенты/ЛИЧНЫЕ_ФИНАНСЫ/_КОНТЕКСТ/Apps_Script_телеграм.js` → Ctrl+A → Ctrl+C
2. Apps Script, поле кода → Ctrl+A → Ctrl+V → сохранить
3. Сверху функция **`stopWebhook`** → **Выполнить** — бот замолкает сразу
4. Потом функция **`installPolling`** → **Выполнить**
5. Через минуту боту: `еда 350` — ждать «Записал во входящее»

Не запускай `registerWebhook`, пока спам не остановили.
