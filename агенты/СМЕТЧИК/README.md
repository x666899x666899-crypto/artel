# Агент «Сметчик»

Считает сметы на изделия по вашим файлам: шаблоны Форы, прайс 2026, Excel нестандарта.

## Как вызвать

```
@сметчик посчитай световые буквы 5 шт, высота 40 см, на композите
```

```
@сметчик это нестандарт — считай по Excel материалов с нашим коэффициентом
```

```
@сметчик вот как посчитал менеджер — сравни с твоим расчётом, покажи расхождения
```

Для партнёров укажите колонку цен: `клиент РПК, колонка РПК`.

## Три контура расчёта

| Контур | Что считает | Источник |
|---|---|---|
| **Прайс типовых** | печать, плёнка, листовые, полиграфия, мелочёвка, монтаж, дизайн | `10_Финансы_и_аналитика/Прайсы/Price_2026_*.md` |
| **Фора** | 71 стандартное изделие: буквы, короба, ПК, неон, таблички, каркасы | `03_КП_и_сметы/Расчёты/Фора_шаблоны/` |
| **Нестандарт** | разовые изделия вне шаблонов | `Расчёты/Смета_бланк.xlsm` + коэффициент наценки |

## Что вы получите

1. **Для клиента** — короткий блок под Telegram: что делаем, из чего, срок, сумма.
2. **Раскладка** — таблица с источником каждой цены, чтобы проверить построчно.
3. **Вопросы** — что уточнить, чтобы смета стала боевой.

## Правила

- Считает только по файлам базы. Нет цены — пишет «цена не найдена», не выдумывает.
- Монтаж и спецтехника — отдельной строкой от производства.
- При расхождении цен верит свежему `Материалы.xlsx`, а не шаблону изделия.
- Себестоимость и наценки в клиентский блок не попадают.
- Финальную цену утверждаете вы.

## Папки агента

| Папка | Зачем |
|---|---|
| `_ЛОГИ/` | Каждый расчёт: что считал, каким контуром |

| `_КОНТЕКСТ/анти-паттерны.md` | Ошибки, чтобы не повторялись |
