# Агент «Уборщик»

Разбирает файлы и раскладывает их по папкам базы знаний АРТЕЛЬ.

## Как вызвать

В чате Cursor:

```
@уборщик разбери папку 00_Входящее
```

```
@уборщик наведи порядок на рабочем столе
```

```
@уборщик найди дубликаты в 09_Документы
```

```
@уборщик найди дубликаты в 00_Входящее
```

## Режим дедупликации

1. Сканирует папку по **хэшу содержимого** (имена не важны).
2. Оригинал остаётся — обычно самый ранний файл в «правильной» папке.
3. Копии **переносит** (не удаляет!) в `98_Дубликаты_на_проверку/`.
4. Отчёт: `98_Дубликаты_на_проверку/ОТЧЁТ.md`.
5. Группы >5 файлов или файлы >1 ГБ — только в отчёт, без переноса.
6. Финальное удаление — **только вашими руками**.

Протокол: `агенты/УБОРЩИК/_КОНТЕКСТ/дедуп_протокол.md`

## Что делает (разбор)

1. Смотрит список файлов и читает каждый.
2. Показывает план: что куда переместит и под каким именем.
3. Ждёт вашего «да».
4. Перемещает, пишет лог, даёт короткий отчёт.

## Правила безопасности

См. `.cursor/rules/безопасность-файлов.mdc` — **удаление запрещено**.

- Лишнее → `99_Архив/`, не в корзину и не `Remove-Item`.
- Одна попытка операции — не сработало → стоп, спросить Сергея.
- Облака (Яндекс.Диск и др.) — не трогать терминалом.
- Сначала план, потом действие. После — проверка и отчёт.

## Папки агента

| Папка | Зачем |
|---|---|
| `_ЛОГИ/` | Отчёты по каждой уборке: что куда переместил |
| `_КОНТЕКСТ/примеры/` | Удачные решения — образец на будущее |
| `_КОНТЕКСТ/уроки.md` | Ошибки и поправки, чтобы не повторялись |

Правила агента: `.cursor/rules/уборщик.mdc`
