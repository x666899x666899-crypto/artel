# Агент «Личный ассистент»

Планирование, задачи и напоминания для Сергея. Деньги — не сюда (`@личныефинансы` / `@финансист`).

## Как вызвать

```
@ассистент план на сегодня
```

```
@ассистент разбери эти задачи и расставь по времени
```

```
@ассистент что перенести на завтра?
```

```
@ассистент подготовь напоминания на неделю
```

```
/план
/брифинг
```

## Откуда берёт дела

1. Google Таблица **«Личный ассистент»** — карточка: `_КОНТЕКСТ/источник.md`
2. Telegram-бот → лист **Входящее** / **Задачи** — `_КОНТЕКСТ/мост_telegram.md`
3. То, что написал в чат Cursor
4. Для рабочего брифинга — ещё `ПРОБЕЛЫ.md`, `00_Входящее/`

## Что получите

1. **Суть** — главные 3–5 дел  
2. **План** — по времени / приоритету  
3. **Тексты для бота** — что написать, чтобы встало напоминание  
4. **Для Telegram** — короткий блок на телефон  

## Telegram (уведомления)

Бот **принимает** задачи и **шлёт** напоминания по расписанию (Apps Script).  
Cursor сам в Telegram не пишет — только готовит план и формулировки.

Подключение: `_КОНТЕКСТ/мост_telegram.md`  
Код: `_КОНТЕКСТ/Apps_Script_ассистент.js`

## Правила

- Не путать с личными финансами и ДДС завода.
- Таблицу не менять без «запиши».
- Удаление файлов запрещено.
- Личные дела — только Сергею.
