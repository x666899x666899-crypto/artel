# Мост: Telegram → задачи и напоминания

> Личный ассистент. Бот принимает задачи и шлёт уведомления.  
> Это **отдельный** бот от «Личные финансы» (`@личныефинансы` / mikhalchekbot) — один бот = один скрипт опроса.

## Как устроено

```
Ты в Telegram                      Google
+ позвонить Василию            → Задачи
напомни завтра 9:00 …          → Напоминания
список / план                  → ответ списком
(в нужное время)               ← бот сам пишет напоминание
```

Ответ на команду — обычно в течение **минуты** (опрос раз в минуту).  
Напоминание уходит, когда сработает проверка (раз в 5 минут).

## Что сделать Сергею (один раз, ~10 минут)

### 1. Таблица Google

1. [docs.google.com](https://docs.google.com) → Создать таблицу  
2. Имя: **Личный ассистент**  
3. Расширения → Apps Script  
4. В Cursor открой `Apps_Script_ассистент.js` → Ctrl+A → Ctrl+C  
5. В Apps Script Ctrl+A → Ctrl+V → Сохранить  
6. В **первой строке кода** вставь ID таблицы (из URL: `/d/ВОТ_ЭТОТ_ID/edit`) в `SPREADSHEET_ID`  
7. Функция **`setupAssistant`** → Выполнить → разрешить доступ Google  

Пришли ссылку на таблицу в Cursor — допишу в `источник.md`.

### 2. Бот Telegram (новый)

1. @BotFather → `/newbot`  
2. Имя: например `Ассистент Сергей`  
3. Username: например `artel_assistant_bot`  
4. Токен пришли **только в этот чат Cursor** (или в `99_Конфиденциально/` сам) — никому больше  

### 3. Свойства скрипта

Apps Script → шестерёнка → Свойства скрипта:

| Свойство | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather |
| `ALLOWED_CHAT_ID` | можно не ставить: запомнится с первого `/start` |

Опционально (умные ответы обычным текстом):

| `DEEPSEEK_API_KEY` | ключ DeepSeek |

### 4. Запуск опроса и напоминаний

1. Функция **`installPolling`** → Выполнить  
2. Функция **`installReminders`** → Выполнить  
3. В Telegram боту: `/start`  
4. Проверка: `+ купить воду` → должен ответить, что записал  
5. `напомни через 5 минут тест` → через ~5–10 мин придёт пуш  

**Не запускай** `registerWebhook`, пока не уверен — у вас уже был спам на старом вебхуке у финансового бота. Опрос (`installPolling`) надёжнее.

## Команды бота

| Пишешь | Что будет |
|---|---|
| `+ текст` или `задача текст` | новая задача |
| `список` / `задачи` | открытые задачи |
| `готово 3` / `сделано 3` | закрыть задачу с id 3 |
| `напомни ДД.ММ ЧЧ:ММ текст` | напоминание на дату |
| `напомни завтра 9:00 текст` | на завтра |
| `напомни через 30 минут текст` | относительное |
| `план` | открытые задачи + ближайшие напоминания |
| `утро` | короткий брифинг из таблицы |
| `/help` | меню |

Обычный текст без `+` / команд — если есть DeepSeek, ответит как помощник по плану; без ключа — подскажет команды.

## Утренний пуш (по желанию)

После `installReminders` можно включить:

1. Свойство `MORNING_PUSH` = `1`  
2. Время по Улан-Удэ: свойство `MORNING_HOUR` = `8` (по умолчанию 8)

Бот раз в день около этого часа пришлёт «Утро» со списком открытых задач.

## Связь с Cursor

```
@ассистент составь план на завтра и тексты напоминаний для бота
```

Агент даст формулировки — ты копируешь в бота **или** пишешь «запиши» и агент готовит строки для таблицы (вносит человек / бот).
