## Листы

| Лист | Кто пишет | Зачем |
|---|---|---|
| **Входящее** | бот сразу | сырой текст/голос/фото из Telegram |
| **Задачи** | бот + агент по «запиши» | список дел: статус, срок, приоритет |
| **Напоминания** | бот / агент | когда пушнуть в Telegram |
| **План_дня** | агент / бот «план» | снимок плана на дату |
| **Справка** | разово | команды бота |

## Колонки «Задачи»

| Колонка | Смысл |
|---|---|
| id | номер строки / авто |
| Создано | дата-время |
| Текст | что сделать |
| Срок | дата или дата+время |
| Приоритет | 1 высокий … 3 низкий |
| Статус | открыто / сделано / отмена |
| Источник | telegram / cursor / вручную |
| Chat_id | служебное |
| Комментарий | уточнение |

## Колонки «Напоминания»

| Колонка | Смысл |
|---|---|
| id | |
| Когда | дата-время пуша (UTC+8) |
| Текст | что написать в Telegram |
| Статус | ждать / отправлено / отмена |
| Задача_id | связь с Задачи (если есть) |
| Chat_id | куда слать |

## Связь с Cursor

- `@ассистент` читает эти листы (export / вставка / описание).
- Планы «на сохранение» можно класть в `агенты/ЛИЧНЫЙ_АССИСТЕНТ/планы/YYYY-MM-DD.md`.
- Пуш в Telegram делает **только** Apps Script по триггеру `checkReminders`.
