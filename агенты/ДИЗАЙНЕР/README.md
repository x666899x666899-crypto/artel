# Агент «Дизайнер»

ТЗ на макет, проверка файлов под производство, оценка услуг дизайна по прайсу, брифы и правки.

**Фирстиль самой АРТЕЛИ** — только по гайдбуку 2026 (выжимка в базе + PDF на сервере). Клиентские макеты — по бренду клиента.

## Как вызвать

```
@дизайнер ТЗ на вывеску: световые буквы на композите, высота 40 см, текст «АРТЕЛЬ»
```

```
@дизайнер вот скрин макета / файл — проверь, готов ли к печати и монтажу
```

```
@дизайнер сколько взять за дизайн входной группы? Логотип у клиента есть.
```

```
@дизайнер клиент прислал правки: [текст]. Сформулируй список правок дизайнеру.
```

```
@дизайнер для КП нужен визуал — куда вставить фото макета и что подписать
```

```
@дизайнер макет поста / бланка для АРТЕЛЬ — сверь с фирстилем, что поправить
```

## Что делает

| Задача | Результат |
|---|---|
| ТЗ на макет | чек-лист параметров + вопросы + блок для Telegram |
| Проверка файла/скрина | ок / нет по пунктам готовности к производству |
| Оценка дизайна | цена «от» из прайса 2026, без выдуманных цифр |
| Правки / бриф | короткий список для дизайнера или клиента |
| Визуал КП | куда сослаться на картинку в структуре КП |
