# 00_Входящее

Сюда попадает всё новое: документы, переписка, черновики, файлы «на разбор».

## Как называть файлы

`YYYY-MM-DD_краткое-описание.ext` — например: `2026-08-04_запрос-клиента-магнит.xlsx`

## Что делать дальше

1. Разобрать файл по нужной папке (01–10).
2. Если непонятно куда — оставить здесь и спросить ИИ.
3. Обработанные оригиналы переносить в `_архив/` или `99_Архив/`.
4. После разбора — обновить `ПРОБЕЛЫ.md`.

Подробно: `08_Команда/Как_работать_с_базой.md`
