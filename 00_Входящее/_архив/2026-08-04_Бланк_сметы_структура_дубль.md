# Бланк сметы на нестандарт — структура

> Источник: рабочая Excel-таблица сметы, лист 1. Выгружено 2026-08-04.
> Это описание структуры рабочего бланка. Сам расчёт ведётся в Excel.

## Шапка

- Клиент
- Адрес
- Описание заказа

## Колонки

| № | Наименование | Единица измерения | Количество | Цена за единицу, руб. | Сумма, руб. |
|---|---|---|---|---|---|

Менеджер заполняет только **количество**. Цена за единицу подтягивается из прайса материалов (`99_Конфиденциально/2026-08-04_Цены_материалов_для_смет.md`).

## Разделы бланка

Каждый раздел помечен буквой — `A` или `B`. Что означает пометка, нужно уточнить у Василия.

| Раздел | Метка |
|---|---|
| Огстекло, акрил | A |
| Пластик ПВХ | A |
| Метал/Оцинковка/Композит | A |
| Светодиоды/светотехника | A |
| Блоки питания | A |
| Электрика/Комплектующие | A |
| Расходные материалы | A |
| Плёнки самоклеющиеся | A |
| Широкоформатная печать | B |
| Интерьерная печать | B |
| Монтажные работы | B |
| Фрезеровка/плоттерная резка | B |
| Фанера/Брусок | A |
| Карманы/зажимы для стендов/POS | B |
| Борт алюминиевый | A |
| Транспортные/Спецтехника/Командировочные | B |

## Итоги

1. `Производство рекламного изделия` — сумма по разделам
2. `Итого стоимость` × **коэффициент наценки 3**
3. `Итого, руб.`
4. `Скидка, %` — по умолчанию 3
5. `Скидка, руб.`
6. `Итого с учётом скидки, руб.`

## Что требует уточнения

- К каким строкам применяется коэффициент наценки 3 — ко всей смете или только к материалам. В пустом бланке формулу не видно.
- Что означают метки `A` и `B` у разделов.
- Монтаж и спецтехника сидят внутри этого же бланка (разделы «Монтажные работы» и «Транспортные/Спецтехника»), хотя по правилам базы их считают отдельно от сметы производства.
