# База знаний — структура папок для бизнеса

> Исходник из курса (Telegram Desktop, 2026-08-10). Адаптация под АРТЕЛЬ — `08_Команда/Как_работать_с_базой.md`

## Зачем это нужно

Cursor работает с папками. Чем лучше организованы твои файлы — тем умнее ответы ИИ.
Когда ты спрашиваешь «напиши КП» — ИИ смотрит в твои папки, находит прайсы, примеры, контекст и использует их.

## Универсальная структура

```
МОЙ_БИЗНЕС/
├── 00_Входящее/          ← сюда бросаешь всё новое
├── 01_Бизнес/            ← о компании: кто мы, что делаем, УТП
├── 02_Клиенты/           ← папки по клиентам или сделкам
├── 03_Продажи/           ← КП, скрипты, шаблоны
├── 04_Финансы/           ← таблицы, отчёты, прайсы
├── 05_Команда/           ← регламенты, инструкции, должности
├── 06_Маркетинг/         ← посты, тексты, планы
├── 07_Документы/         ← договоры, акты, шаблоны
└── .cursorrules          ← главный файл контекста
```

## Главный файл — README.md

В корне папки создай файл `README.md` — это «паспорт» твоего бизнеса для ИИ.

## Проверка — всё ли настроено

```
Изучи структуру моих папок и файл README.md.
Скажи: что ты знаешь о моём бизнесе? Что в базе есть, а чего не хватает?
```
