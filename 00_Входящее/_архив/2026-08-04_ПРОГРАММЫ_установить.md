> Чеклист для встречи 1 и домашки. АРХИВНАЯ КОПИЯ (2026-08-04). Рабочая версия: `01_О_компании/ИТ_и_программы.md`

## Обязательно сейчас (до / на встрече 1)

| # | Программа | Зачем | Ссылка / как |
|---|---|---|---|
| 1 | **Cursor** | основная рабочая среда | https://cursor.com → Download (Windows) · подписка Pro ~$20 |
| 2 | **VPN: Happ** | чтобы работали Claude и др. модели | https://happ.su |

| 5 | **Зарубежная карта** (если ещё нет) | оплата Cursor | «Плати по миру» / как в `ДО_ВСТРЕЧИ.pdf` |

Проверка: VPN включён → открываются cursor.com и claude.ai · Cursor открывается · чат отвечает по-русски.

## Поставить на встрече 1 (через агента Cursor - 5-10 мин)

| # | Программа | Зачем |
|---|---|---|
| 6 | **Python 3** | чтение Excel, таблицы, простые скрипты |
| 7 | **Microsoft Edge / Chrome** | уже есть; браузер для Битрикс и админок |

Опционально: **Java (JRE)** — если понадобится библиотекам для чтения офисных/PDF.

## Не ставить на встрече 1 (позже по плану)

| Программа | Когда |
|---|---|
| Plaud (приложение / диктофон) | неделя 3 - расшифровка встреч |
| n8n / Node.js | неделя 4+ - автоматизация |
| Ideogram | по желанию - макеты (можно браузер) |
| Claude Code отдельно | не нужен: Claude работает внутри Cursor |
| Фора / Битрикс | уже есть - не трогаем |
