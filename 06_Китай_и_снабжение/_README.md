# 06_Китай_и_снабжение

Закупки в Китае, поставщики, запросы.

## Как называть файлы

- `Направления_закупок.md`
- `Поставщики/название-поставщика.md`
- `_Шаблон_запроса_поставщику.md`

## Что сюда класть

- Направления закупок (LED, сувениры, полиграфия и т.д.)
- База поставщиков (контакты — публичные; цены — в `99_Конфиденциально/`)
- Шаблоны запросов поставщикам
