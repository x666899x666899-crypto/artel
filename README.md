## Как работает база

1. **Новое** → `00_Входящее/` (имя `YYYY-MM-DD_описание.ext`), потом разбор по папкам.
2. **ИИ читает** `README.md` → `AGENTS.md` → релевантные папки по задаче.
3. **Проверка** — команда `/проверка` в чате (см. `08_Команда/Как_работать_с_базой.md`).

Ключевые файлы: `AGENTS.md` (команды), `ПРОБЕЛЫ.md`, `08_Команда/Промпты_личный_помощник.md`, `07_Маркетинг/Промпты_тексты_и_КП.md`.
