# 98_Дубликаты_на_проверку

Сюда уборщик **переносит** (не удаляет!) копии файлов с одинаковым содержимым.

## Как это работает

1. Команда: `@уборщик найди дубликаты в [папка]`
2. Агент сравнивает файлы по **хэшу содержимого**, не по имени.
3. Оригинал остаётся на месте — обычно самый ранний файл в «правильной» папке.
4. Копии переносятся сюда, структура пути сохраняется в подпапках.
5. Отчёт: `ОТЧЁТ.md` — группы, оригиналы, копии, сколько места можно освободить.

## Важно

- **Финальное удаление — только руками Сергея.** Агент ничего не удаляет.
- Группы >5 файлов или файлы >1 ГБ — только в отчёт с пометкой «проверь вручную», без переноса.
- Сервер `\\serverartel` — только по явной команде и на **одну конкретную** папку.

## После проверки

Просмотрел отчёт → решил, что точно лишнее → удаляешь **сам** или переносишь в `99_Архив/`.
