# 03_КП_и_сметы

Коммерческие предложения, сметы, правила расчёта.

## Как называть файлы

- `Правила_расчёта.md` — внутренние принципы ценообразования
- `_Шаблон_КП.md` — шаблон КП
- `Архив_КП/YYYY-MM-DD_клиент_объект.md` — готовые КП

## Что сюда класть

- Шаблоны и примеры КП (`_Шаблон_КП.md`)
- Промпты для КП: `07_Маркетинг/Промпты_тексты_и_КП.md` (команды `/кп`, `/кп-холод`)
- Правила расчёта (материалы × 2.7 и др.)
- Успешные сделки как образцы
