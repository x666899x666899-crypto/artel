# КП АРТЕЛЬ — куда смотреть

Шаблоны лежат в базе:

| Файл | Что |
|---|---|
| **`03_КП_и_сметы/_Шаблоны_КП/АРТЕЛЬ_шаблон_КП.html`** | Визуальный бланк A4 — открыть в браузере, печать в PDF |
| **`03_КП_и_сметы/_Шаблоны_КП/АРТЕЛЬ_КП_бланк_структура.md`** | Этот файл — порядок блоков |
| **`07_Маркетинг/Промпты_тексты_и_КП.md`** | Тексты `/кп`, `/кп-холод` |
| **`03_КП_и_сметы/_Шаблон_КП.md`** | Старый markdown-шаблон (таблица) |

## Порядок блоков (как в HTML)

1. Шапка (бренд + контакты)
2. Заголовок + клиент / дата / №
3. **Hero-визуал** (всегда до цены)
4. Параметры заказа
5. Стоимость (таблица)
6. Входит / не входит
7. Срок и условия
8. Рекомендация
9. Подпись + CTA
10. Блок «Для Telegram» (не в PDF)

## Как тестировать

1. Сметчик считает → цифры без себестоимости.
2. Агент заполняет HTML из `_Шаблоны_КП/АРТЕЛЬ_шаблон_КП.html`.
3. Готовое КП → `03_КП_и_сметы/Архив_КП/YYYY-MM-DD_клиент_объект_КП.html`.
4. Открыть в браузере → Ctrl+P → PDF.

## Пример теста

`03_КП_и_сметы/Архив_КП/2026-08-10_БРК_АЗС_Краснодонская_КП.html` — по смете БРК Краснодонская (1 938 316 ₽).
