# Расчёты

Рабочие расчётные материалы:

- **Таблица материалов** для нестандарта (раскладка + формула наценки + монтаж)
- **Выгрузки из Форы** (стандартные вывески)
- Примеры смет по выполненным заказам

## Как называть файлы

- `Таблица_материалов.xlsx`
- `Фора_выгрузка_YYYY-MM-DD.xlsx`
- `Смета_YYYY-MM-DD_клиент_объект.xlsx`

> Сюда нужно положить актуальную Excel-таблицу материалов и примеры смет — см. `ПРОБЕЛЫ.md`.
