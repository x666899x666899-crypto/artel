# Правила расчёта

> Обновлено по аудиту 29.07.2026. ИИ работает ПОВЕРХ существующих контуров, не заменяет их.

## Три контура расчёта (не путать!)

| Контур | Чем считаем |
|--------|-------------|
| **Типовые изделия** (кв.м / погонные метры / шт) | прайс в Google Таблицах / Excel → `10_Финансы_и_аналитика/Прайсы/` |
| **Стандартные вывески** | программа **Фора** (живой контур — не трогаем). Копии расчётных шаблонов: `Расчёты/Фора_шаблоны/`, обзор — `Расчёты/Фора_изделия.md` |
| **Нестандарт** | Excel-таблица материалов: менеджер делает раскладку (акрил, борта, диоды, крепёж) + формула наценки + монтаж |

- Менеджеры сами делают раскладку по материалам.
- Цены материалов в таблицах обновляются вручную.
- **Монтаж и спецтехника считаются отдельно** от сметы производства.

## Механика бланка сметы (из «СМЕТА БЛАНК.xlsm»)

Рабочий файл: `Расчёты/Смета_бланк.xlsm` (листы: Бланк, Прайс_1 — актуальный, Прайс_2 — старые цены).

1. Шапка: клиент, адрес, описание заказа.
2. Позиции по категориям прайса; количество × цена клиента = сумма.
3. Маркер **A** — материалы, маркер **B** — работы/услуги (печать, монтаж, фрезеровка, транспорт).
4. Итог «Производство рекламного изделия» умножается на **коэффициент наценки 3** (задаётся в бланке).
5. Дальше: Итого → Скидка % → Итого с учётом скидки.

Особые условия из прайса:
- Монтаж баннера: если сумма меньше минимального выезда — ставим **минималку 2800 ₽**.
- Выклейка плёнок: **+500 ₽** за каждый дополнительный цвет.
- Демонтаж плёнки: стоимость оценивать по фото или после замера.
- Командировочные: 2500 ₽/сутки на человека, курортная зона — 4000 ₽.

## Стандартные вывески — шаблоны Форы (выгрузка 04.08.2026)

Фиксированных цен на стандартные вывески нет: Фора считает параметрически. По каждому из 71 изделия есть `Шаблон.xlsx` в `Расчёты/Фора_шаблоны/` (12 листов: параметры → материалы → работы → ЧПУ → транспорт → % расходников → прибыль → монтаж → налоги). Полный список изделий и инструкция — `Расчёты/Фора_изделия.md`. Внутренние расценки (ЗП, наценки, налоги) — `99_Конфиденциально/Фора_расценки.md`, в КП не показывать. **Цены материалов:** при расхождении между шаблонами — верить свежему `Материалы.xlsx`, колонка «Стоимость» (Сергей, 10.08.2026).

## Правила для ИИ при расчётах

1. Считай **только по нашим прайсам и таблицам**: `Расчёты/Номенклатура_материалов.md` (цены клиента), `Расчёты/Смета_бланк.xlsm`, `10_Финансы_и_аналитика/Прайсы/`. Не выдумывай цены.
2. Если цены на позицию нет — скажи прямо и спроси.
3. В каждой смете показывай раскладку: **материалы, количество, наценка, монтаж** — чтобы можно было проверить.
4. Себестоимость («наша цена») — только в `99_Конфиденциально/Себестоимость_материалов.md`, в КП не показывать.
5. Базовый ориентир для черновой оценки (когда таблиц под рукой нет): **материалы × 2.7** + работа, логистика, монтаж, проектирование. Помечай такой расчёт как черновой.

## Дополнительно

- Для китайских поставок — дополнительные наценки (детали в `99_Конфиденциально/`).
- Доставка рассчитывается отдельно, если не включена в КП. Указывать явно в смете.

## Прайсы

Вести отдельные таблицы: наружная реклама, полиграфия, сувениры, монтаж, дизайн, доставка, сервис.

Файлы: `10_Финансы_и_аналитика/Прайсы/`
