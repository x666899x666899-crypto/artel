# 04_Объекты_и_клиенты

Папка на каждый объект или крупного клиента.

## Как называть папки и файлы

- Папка: `Клиент_НазваниеОбъекта/` — например: `Магнит_вывеска_Трактовая/`
- Внутри: `Карточка_объекта.md`, переписка, заметки, сроки, статус

## Что сюда класть

- Карточки объектов и сделок
- История заказов и переписка
- Чеклисты и статусы этапов производственного цикла
