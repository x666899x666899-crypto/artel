# 11_Битрикс

Выгрузки сделок из Битрикс24 и их анализ.

## Контекст

- Две воронки: **«Продажи»** и **«Сопровождение»**.
- Подключены: Telegram, MAX, телефония Ростелеком (записи звонков в сделках), Авито.
- Смотрят менеджеры и РОП. Интегратор — Миша.

## Как называть файлы

- `Выгрузка_сделок_YYYY-MM-DD.csv` / `.xlsx`
- `Анализ_YYYY-MM-DD_тема.md`

## Типовые задачи ИИ

- Ежедневный скрининг сделок → короткий отчёт в Telegram-формате (собственнику и РОПу).
- Анализ воронки: зависшие сделки, сроки, суммы.
- Разбор переписки и записей звонков (перспектива).
