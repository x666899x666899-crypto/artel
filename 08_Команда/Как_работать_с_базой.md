# Как работать с базой знаний АРТЕЛЬ

> Принципы из курса «База знаний — структура папок» (адаптировано под АРТЕЛЬ, 2026-08-10).
> Исходный гайд: `00_Входящее/_архив/2026-08-10_База_знаний_структура_гайд.md`

## Зачем так устроено

Cursor работает с **папками и файлами**. Чем лучше разложены документы — тем точнее ответы ИИ.

Когда просишь «напиши КП» или «посчитай смету» — ассистент ищет в базе прайсы, примеры, правила и подставляет **наши** цифры, а не выдумывает.

## Три файла — точка входа

| Файл | Зачем |
|------|-------|
| `README.md` | Паспорт компании: кто мы, контакты, карта папок |
| `AGENTS.md` | Правила для ИИ: роль, расчёты, стиль, быстрые команды |
| `ПРОБЕЛЫ.md` | Чего не хватает — живой чеклист |

В Cursor вместо старого `.cursorrules` — `AGENTS.md` + `.cursor/rules/*.mdc`.

## Рабочий цикл

### Для Сергея

1. **Новый файл** → бросить в `00_Входящее/` с именем `YYYY-MM-DD_описание.ext`.
2. В чате: **`/входящее`**, «разбери входящее» или «положи файл X в нужную папку».
3. Утром или по ощущению: **`/брифинг`** — приоритеты на день; раз в неделю — **`/проверка`**.

### Для ИИ-ассистента

Перед любой задачей:

1. Прочитать `README.md` и `AGENTS.md` (если ещё не в контексте).
2. Открыть **релевантные папки** по типу задачи (см. таблицу в `AGENTS.md`, раздел 6).
3. Считать только по файлам базы; нет данных — сказать и предложить, откуда взять.
4. Новые файлы без явного места — в `00_Входящее/`.
5. После добавления данных — обновить `ПРОБЕЛЫ.md`.

| Реквизиты, себестоимость | `99_Конфиденциально/` |
| Личные выписки, бюджет Сергея | `99_Конфиденциально/Личные_финансы/` |
| Пост для соцсетей | `07_Маркетинг/` |
| Договор, акт | `09_Документы/` |
| Непонятно куда | `00_Входящее/` |

## Проверка — база работает?

Команда **`/проверка`**: ИИ изучает структуру и `README.md`, отвечает:

- что знает о бизнесе;
- что уже есть в базе;
- чего не хватает (по `ПРОБЕЛЫ.md`).

Если ответы конкретные про АРТЕЛЬ — база настроена ✅
