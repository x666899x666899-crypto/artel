# Промпты — личный ИИ-помощник (АРТЕЛЬ)

> Адаптация курса «Личный ИИ-помощник» под АРТЕЛЬ, 2026-08-10.
> Исходник: `00_Входящее/_архив/2026-08-10_Личный_помощник_промпты_гайд.md`

Cursor читает файлы в папке ARTEL. Чем больше прайсов, регламентов и примеров в базе — тем точнее ответы.

**Как вызывать:** быстрые команды в чате (см. `AGENTS.md`) или скопировать промпт ниже.

---

## Быстрые команды ↔ промпты

| Команда | Задача |
|---------|--------|
| `/брифинг` | Утренний приоритет на день |
| `/входящее` | Разобрать `00_Входящее/` |
| `/встреча` | Подготовка к звонку/встрече с клиентом |
| `/разбор` | Итоги встречи из текста/расшифровки |
| `/ответ` | Ответ на трудное письмо (2 варианта) |
| `/риски` | Проверить идею/решение как критик |
| `/тз` | Делегировать задачу сотруднику |
| `/регламент` | Регламент из переписки/звонка |
| `/аудит` | Где теряется время и деньги |
| `/итог` | Суть документа или диалога |
| `/проверка` | Аудит базы знаний |
| `/смета`, `/кп` | Расчёт и коммерческое предложение |
| `/личные`, `@личныефинансы` | Личные деньги Сергея (не ДДС АРТЕЛЬ) |
| `/план`, `@ассистент` | План дня/недели, задачи, тексты напоминаний в Telegram |

---

## 1. Утренний брифинг — `/брифинг`

```
Посмотри на файлы базы АРТЕЛЬ: ПРОБЕЛЫ.md, 00_Входящее/, 11_Битрикс/ (если есть).
Что сегодня важного для Сергея (маркетинг, финансы, продажи)?
Что мог упустить?
Дай 5 приоритетных действий на сегодня.
Формат: коротко, для Telegram, без воды.
```

---

## 2. Разобрать входящее — `/входящее`

```
В папке 00_Входящее/ лежат новые файлы.
Разбери каждый: что это, что с этим делать, куда переложить (по карте в 08_Команда/Как_работать_с_базой.md).
Составь список действий. Обработанное — в _архив/ или 99_Архив/. Удалять нельзя.
```

---

## 3. Подготовка к встрече — `/встреча`

```
Завтра встреча с клиентом: [имя, компания, направление].
Цель: [продать / согласовать / уточнить ТЗ].

Помоги подготовиться (контекст АРТЕЛЬ, tone of voice из 07_Маркетинг/):
1. Что важно узнать у клиента?
2. Какие возражения могут быть (цена, сроки, монтаж)?
3. С чего начать встречу?
4. Чем закончить — конкретный следующий шаг?
```

---

## 4. Разбор итогов встречи — `/разбор`

```
Вот текст встречи: [вставь расшифровку или @файл]

Выдели:
1. Договорённости — задачи по пунктам
2. Боли, возражения, интерес клиента
3. Следующий шаг — кто что делает и когда
4. Что подготовить с нашей стороны (смета, КП, замер, макет)
```

*Также можно использовать `/задачи` для простого списка задач.*

---

## 5. Ответ на трудное письмо — `/ответ`

```
Мне написали: [текст]

Нужно: [согласиться / отказать / уточнить / перенести срок].

Напиши ответ в стиле АРТЕЛЬ (07_Маркетинг/Tone_of_voice.md): деловой, живой, коротко.
Дай 2 варианта — мягче и прямее. Без себестоимости и внутренних цифр.
```

---

## 6. Проверить решение — `/риски`

```
Я хочу сделать: [идея или решение]

Выступи как жёсткий критик и опытный предприниматель в рекламном производстве.
Найди 3–5 слабых мест.
Где может провалиться (сроки, монтаж, смета, кассовый разрыв)?
Предложи как закрыть риски.
```

---

## 7. Делегировать задачу — `/тз`

```
Поставить задачу сотруднику АРТЕЛЬ.

Задача: [что сделать]
Сотрудник: [должность, опыт]
Срок: [дата]

Напиши чёткое ТЗ: что делать, как делать, критерий «готово».
Формат для Telegram или Битрикса.
```

---

## 8. Регламент из звонка — `/регламент`

```
Диалог / переписка: [текст или @файл]

Создай пошаговый регламент для сотрудника АРТЕЛЬ.
Шаблон: 08_Команда/_Шаблон_регламента.md.
Формат: «Если X — делай Y». В конце — чеклист самопроверки.
```

---

## 9. Где теряется время — `/аудит`

```
Типичный рабочий день Сергея: [опиши как проходит]

Найди:
1. Где больше всего теряется времени?
2. Что повторяется каждую неделю — можно автоматизировать (сметы, КП, Битрикс)?
3. Что делает сам, хотя мог бы делегировать менеджерам?

Предложи 3 конкретных изменения с учётом целей из 01_О_компании/Цели_автоматизации.md.
```

---

## 10. Резюме документа — `/итог`

```
Прочитай: [@файл или вставь текст]

Дай:
1. Суть в 3 предложениях
2. Ключевые цифры и факты
3. Что требует внимания или решения Сергея
Формат — для телефона.
```

---

## 11. Личные финансы — `/личные` / `@личныефинансы`

```
Личные деньги Сергея, не ДДС АРТЕЛЬ.
Правила: .cursor/rules/личные-финансы.mdc
Цифры: 99_Конфиденциально/Личные_финансы/ и то, что в этом чате / на фото.
Нет данных — сказать прямо. Журнал не менять без «запиши».
Сводка: приход, расход, сальдо, крупные статьи + блок для Telegram.
```

Задача: [сводка за период / разбор выписки / можно ли потратить X / бюджет vs факт]

---

## 12. План и задачи — `/план`, `@ассистент`

```
Личный ассистент Сергея. Правила: .cursor/rules/личный-ассистент.mdc
Смотри: агенты/ЛИЧНЫЙ_АССИСТЕНТ/ (таблица задач, планы/), ПРОБЕЛЫ.md, 00_Входящее/ если рабочий брифинг.
Дай 3–5 приоритетов, что отложить, готовые тексты для Telegram-бота (+ задача / напомни …).
Коротко, для телефона. Деньги не считай.
```

Задача: [план на сегодня / неделю / разбор списка / напоминания]

1. **Сохраняй удачные промпты** — дописывай в этот файл.
2. **Обновляй `AGENTS.md`** — если в бизнесе что-то изменилось.
3. **Корми базу** — прайсы, примеры КП, регламенты → точнее ответы.
